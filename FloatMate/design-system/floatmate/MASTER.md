# FloatMate 视觉设计系统

> 方向：Windows 桌面小组件 × iPhone 原生亮色层级。保持轻量、克制、清晰，不复制受限字体或平台专属素材。

## 设计旋钮

- 风格差异度：3/10（安静、居中、最小化）
- 动效强度：3/10（仅 180ms 状态淡入，遵循系统“减少动画”）
- 信息密度：7/10（桌面侧边工具，信息一眼可扫）
- 材质：半透明白色表面、弱边框、单层柔和阴影

## 语义色

| Token | 色值 | 用途 |
|---|---:|---|
| Canvas | `#F2F2F7` | iOS grouped background |
| Surface | `#FFFFFF` | 卡片、输入框、浮岛主体 |
| Surface soft | `#F2F2F7` | 指标格、轨道底部、设置分组 |
| Label | `#1C1C1E` | 标题与正文 |
| Secondary label | `#5A5A60` | 辅助信息，白底对比度 6.7:1 |
| Tertiary label | `#63636A` | 最弱可读标签，白底对比度 5.9:1 |
| Separator | `#E3E3E8` | 轻分隔线 |
| Interactive blue | `#0066CC` | 主操作与进度，白底对比度 5.6:1 |
| Focus blue | `#007AFF` | 2px 键盘焦点环、非文字状态 |
| Success | `#1F7A35` | 健康状态文字；圆点可用更明亮的系统绿 |
| Warning | `#A35A00` | 注意状态 |
| Danger | `#D70015` | 删除、紧张状态 |

## 字体系统

- 字体栈：`Segoe UI Variable Text, Microsoft YaHei UI, Segoe UI`
- 原因：使用 Windows 本机可变字体，避免下载 SF Pro 或常驻第三方字体资源。
- 页面标题 17–18 / SemiBold；区块标题 14 / SemiBold；正文 10–12 / Regular；指标 15 / SemiBold。
- 所有性能数字使用 tabular numerals，采样刷新时不横向跳动。
- 小字号不使用浅灰色；最低弱文字采用 `#63636A`。

## 组件

- 浮岛：26px 圆角，白色 86%–100% 不透明度，默认 94%，1px 中性边框。
- 左侧停靠：使用 Windows AppBar 预留真实工作区；完整高度、四角直角、纯白实色表面、无浮动阴影，仅保留右侧 1px 分隔线；不可自动收起，标题显示为“本地助手 / ON DEVICE”。
- 卡片：17px 圆角，白色表面；设置采用 grouped form 分组。
- 分段导航：灰色轨道，选中项为白色胶囊；不依赖颜色单独表达状态。
- 主按钮：深系统蓝底 + 白字；悬停/按下只改变颜色，不改变尺寸。
- 任务进度：未完成区保持白色空轨道并带 1px 中性轮廓，进行中按百分比填充蓝色、完成填充绿色；零进度不显示数值。
- 快捷记录：统一白卡和中性灰图标容器，不为每种日常动作分配独立颜色。
- 输入：白底、中性边框、聚焦时 2px 系统蓝边框。
- Toast：白色浮层、弱阴影、3 秒消失；删除可在 5 秒内撤销。

## 交互与无障碍

- 所有按钮使用原生 WPF `Button`，键盘可达并有可见焦点环。
- 图标按钮均设置 `AutomationProperties.Name` 和 ToolTip。
- 健康状态同时显示文字与圆点，不只靠颜色表达。
- 页面切换 180ms ease-out；若 Windows 关闭客户端动画则完全跳过。
- 桌面端紧凑按钮至少 28×28px，主要操作 32–36px；不套用移动端 44pt 规则。
- 正常文字对比度至少 4.5:1；边界和进度属于非文字视觉元素，至少 3:1 或以形状补充。

## 禁止项

- 不使用暗色玻璃、霓虹发光、多重阴影或拟物凹凸效果。
- 不使用低对比灰字、渐变文字、装饰性持续动画。
- 不引入网络字体、图片背景或 UI 框架运行时。
- 不因悬停缩放或移动元素，避免桌面组件抖动。

## 舒适度规则

- 单屏强调色只使用蓝色；绿色仅表示已完成，其他状态保持中性灰。
- 未开始、暂停、零值不是异常，不使用红色、警告色或粗体大数字。
- 零进度隐藏百分比；无记录以“—”呈现，等数据产生后再显示具体数值。
- 页面标题 19–20px，区块标题 16px，任务名称 16px SemiBold；正文与按钮 12–13px，元数据最低 11–12px，以字重和明度共同区分层级。
- 数值使用 tabular numerals，并给百分比固定宽度以保证纵向扫视对齐。
- 模块间距至少 18–20px，卡片间距 12px；内部间距小于外部间距，允许纵向滚动。
- 快捷记录采用一套中性灰视觉，不为每种记录分配单独颜色。
- 提醒只陈述“距上次动作已过去多久”，不使用命令、评价或感叹号。
- 操作反馈使用“已记录 / 已更新 / 已完成”等简洁确认，不夸张庆祝。
- 数据导出独立成区，并按“工作 / 健康”分为两张等权卡片；格式按钮使用中性次级样式，不与新建目标、开始任务等高频主操作争夺注意力。
- 目标详情采用渐进呈现：卡片默认只显示两行摘要，添加/编辑时在原卡片内展开多行输入，避免跳转和额外窗口。
- 应用使用页使用单色蓝色相对时长条、明确的时长文字和中性应用标识；排行不使用多色分类，避免把使用时间表达成警告或评判。
