# 浮岛 FloatMate

一个本地优先的 Windows 桌面助手。它固定在屏幕左侧并预留独立工作区，将系统状态、今日工作、长期计划、健康记录和每日复盘集中在一个低打扰面板中。

GitHub 仓库：[desktop-helpworker](https://github.com/xxxlibraaa-commits/desktop-helpworker)

> 当前阶段：可日常使用的本地版本。数据默认只保存在本机，不需要账号或网络连接。

## 核心模块

| 模块 | 能力 |
| --- | --- |
| 今日工作 | 目标轨道、详细工作内容、进度、状态、预计时长和专注计时 |
| 长期计划 | 多计划折叠管理、XLSX 导入导出、甘特时间线、日期拖动和状态修改 |
| 健康记录 | 喝水、如厕、起身、护眼独立记录，支持提醒与按日复盘 |
| 系统状态 | CPU、内存、系统盘、网络速度及前台应用使用时间 |
| 历史复盘 | 按日期查看目标事件、健康事件和每日摘要 |

## 导出格式

| 数据范围 | 格式 | 内容 |
| --- | --- | --- |
| 今日工作 | XLSM | 任务、详细工作内容、状态、进度、预计时长、专注时长及时间字段 |
| 今日工作 | DOCX | 适合阅读、打印和归档的工作日报 |
| 今日健康 | XLSX | “健康汇总”和“健康明细”两张表，包含总次数、总量及每次发生时间 |
| 长期计划 | XLSX | 甘特视图、状态下拉和可再次导入的任务数据 |

## 已实现

- 系统托盘常驻，左键显示或隐藏；
- Mac 小组件风格的半透明桌面卡片，可拖动、贴边；
- 默认采用桌面小组件层级，浏览器、IDE 等普通窗口会自然覆盖它；
- 设置中可切换成始终置顶的传统悬浮模式；
- CPU、内存、系统盘和网络速度监控；
- 今日应用使用时间：按前台活跃时长统计应用排行，空闲与锁屏时间不计入；
- 长期工作计划：支持月度、40 天和更长周期的多计划管理；
- 可导入现有 XLSX 甘特模板，识别任务、负责人、备注、里程碑及图形时间线；
- 计划任务支持拖动整体时间条、拖动两端调整日期，并可修改状态、进度和明细；
- 可将当前长期计划导出为带甘特视图、状态下拉和任务数据表的 XLSX；
- 今日目标轨道：新增、开始、暂停、完成和删除；
- 每个目标可记录并随时编辑详细工作内容，内容进入本地历史与 XLSM 导出；
- 目标 10% 步进、完整进度、预计时长字段和状态事件；
- 目标专注计时；
- 喝水、如厕、起身和护眼一键记录；
- 喝水、如厕、起身和护眼按事件独立保存；
- 按日期复盘、每日概览和目标/健康时间线；
- 喝水、久坐、护眼提醒，可分别启停与设置间隔；
- 半透明材质、鼠标悬停增强清晰度、失焦自动恢复小组件卡片；
- 可选的 Windows 登录后自动启动；
- 今日完成、专注、喝水和休息摘要；
- 导出按“工作 / 健康”独立分组：工作支持 XLSM 数据表与 DOCX 工作日报；
- 健康支持 XLSX 表格，分别提供类型汇总与逐条明细，包含总次数、总量及每次发生时间；
- 完整键盘焦点环与 Windows UI Automation 读屏标签；
- 目标为空时的引导状态，以及删除目标后的 5 秒撤销；
- 尊重 Windows 的界面动画偏好，关闭系统动画时不播放淡入；
- 等宽系统指标数字，避免刷新时产生视觉跳动。

## 设计系统

界面规范由 `ui-ux-pro-max` 生成并按 FloatMate 的 WPF 约束调整，保存在：

```text
design-system\floatmate\MASTER.md
```

当前方向为白色本地助手界面，信息密度 8/10、动效 3/10。实现优先保证低打扰、键盘可用、清晰对比度和数据扫读效率。
- 长期计划页的局部规范位于 `design-system\floatmate\pages\plan.md`；
- 本地 JSON 持久化；
- 全局快捷键 `Ctrl + Shift + Space`。

## 开发运行

需要 .NET 8 SDK：

```powershell
dotnet run --project .\FloatMate.csproj
```

工作区根目录的 `run.ps1` 会优先使用本项目安装的本地 SDK。由于系统 PowerShell 执行策略可能阻止直接双击脚本，日常使用请双击根目录的 `启动浮岛.cmd`。

## 项目结构

```text
FloatMate/
├─ Controls/                 长期计划页面
├─ Services/                 系统监控、本地存储、导入导出及 Windows 集成
├─ design-system/            FloatMate 视觉与交互规范
├─ App.xaml(.cs)             应用启动、托盘与预览/导出入口
├─ MainWindow.xaml(.cs)      左侧助手主界面与交互逻辑
└─ Models.cs                 本地数据模型
```

## 构建

```powershell
dotnet publish .\FloatMate.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

输出目录：`bin\Release\net8.0-windows\win-x64\publish`。

工作区根目录已经提供 `build.ps1` 和 `启动浮岛.cmd`。当前构建依赖本机已有的 .NET 8 Desktop Runtime；如需分发给没有运行时的电脑，可将发布参数改为 `--self-contained true`。

## 本地数据

数据默认保存在：

```text
%LOCALAPPDATA%\FloatMate\data.json
```

该文件及应用内导出的工作、健康数据不会自动上传到 GitHub。仓库仅保存源代码与说明文档。

退出应用请右键系统托盘图标并选择“退出”。点击窗口上的横线或关闭窗口只会隐藏到托盘。
