FloatMate Windows x64
=====================

1. Double-click FloatMate.exe to start the app.
2. Use the system tray icon to show, hide, or exit FloatMate.
3. Local data is stored at %LOCALAPPDATA%\FloatMate\data.json.
4. Replacing FloatMate.exe does not remove local records.
