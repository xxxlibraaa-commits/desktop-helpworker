# FloatMate v0.4.1

FloatMate 的首个可下载 Windows 版本。适用于 Windows 10/11 x64，发布包为自包含版本，不需要预装 .NET Runtime。

## 主要内容

- 固定在屏幕左侧，通过 Windows AppBar 预留独立工作区；
- 今日目标轨道、详细工作内容、进度、状态、预计时长和专注计时；
- 多个长期计划折叠管理，支持 XLSX 导入导出和甘特时间线拖动；
- 喝水、如厕、起身、护眼独立记录、提醒和历史复盘；
- CPU、内存、系统盘、网络及今日应用使用时间；
- 工作独立导出 XLSM 或 DOCX，健康独立导出汇总与明细 XLSX；
- 新电脑首次安装、环境检查及个人数据备份/恢复脚本。

## 安装

1. 下载 `FloatMate-v0.4.1-win-x64.zip`；
2. 解压到固定目录；
3. 双击 `FloatMate.exe`。

这是尚未购买代码签名证书的个人项目。Windows SmartScreen 可能在首次启动时显示未知发布者提示。

## 升级

1. 从系统托盘退出旧版 FloatMate；
2. 解压新版本并替换原应用文件；
3. 重新启动 FloatMate。

本地数据保存在 `%LOCALAPPDATA%\FloatMate\data.json`，替换程序文件不会删除目标、计划或健康记录。建议升级前在仓库目录运行 `备份数据.cmd`。

## 下载校验

将 `SHA256SUMS.txt` 与 ZIP 一同下载，在 PowerShell 中运行：

```powershell
Get-FileHash .\FloatMate-v0.4.1-win-x64.zip -Algorithm SHA256
```

输出值应与 `SHA256SUMS.txt` 一致。

## 隐私

- 不需要账号；
- 核心功能可离线使用；
- 个人记录不会自动上传；
- 导出文件只在用户主动操作时生成。
